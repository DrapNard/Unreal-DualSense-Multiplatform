# Security Policy

## Supported versions

Security fixes are provided for the latest stable release and, when practical, the current development branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose users to code execution, privilege problems, unsafe device access, or denial of service.

Use GitHub Private Vulnerability Reporting from the repository **Security** tab. Include reproduction steps, affected platform and Unreal version, controller model/transport, impact, and a minimal proof of concept when possible.

The maintainers will coordinate disclosure after a fix is available. Please avoid publishing exploit details before that point.
